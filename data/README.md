# data

`oui.tsv.gz` maps MAC address prefixes (IEEE /24, /28 and /36 assignments)
to vendor names, shortened for display. It is embedded in the binary.

It is generated by `scripts/update_oui.py` from the MAC blocks and registry
vendor names (the third column) in Wireshark's `manuf` file, which is built
from the IEEE's public registries. Wireshark asks that the file be downloaded
at most once a week; regenerate occasionally, not in CI.
